翻译指南
==================

本文记录在翻译过程中遇到过的问题，以及针对这些问题的注意事项。


人名和地名的翻译
----------------------

人名和地名在不同的翻译文件中应该保持一致。地名和战役中很重要的人物的名字，很可能在其他战役中也出现过，请先搜索其他翻译文件。


对斜体字的处理
----------------------

中文印刷不习惯用斜体，目前翻译对 ``<i>``, ``</i>`` 标签的处理如下：

- 在对话、旁白等正文中，将单独的 ``<i>`` 标签换成 ``<b>`` 标签，斜体与粗体同时存在时的 ``<i><b>``, ``<b><i>`` 不变
- 如果斜体用在战役名或场景名，用书名号代替 ``<i>`` 标签
- 目前发现有的地方 ``<span style='italic'>`` 替换成 ``<span style='bold'>`` 无法正常渲染，如果翻译后发现渲染异常，且没有替代方案，则保持原标签不变


使用 msgmerge
----------------------

在以下两个场合需要用 msgmerge:

- 在上游更新后，使用 msgmerge 使得目前工作的 .po 文件和上游同步
- 在提交新的 .po 文件版本前，可能新的翻译文件格式规范和上游不同，需要使用 msgmerge 同步格式

msgmerge 命令行（假设 wesnoth 源码在 ``~/source/wesnoth``, 以 ``wesnoth-tsg`` 为例）：

``msgmerge --previous -U zh_CN.po ~/source/wesnoth/po/wesnoth-tsg/wesnoth-tsg.pot``
